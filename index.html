World models · Embodied AI · Robot learning

I am an incoming M.Eng. student in Computer Science at Beihang University, advised by Prof. Di Huang. I currently research world models at GensPI (ShengShu), where I work on Motus2.

My interest is memory and long-horizon context in world models for embodied agents: how an agent retains and retrieves the history a task actually needs, and how it improves from outcomes it predicts and observes rather than from demonstrations alone. I have approached this from three directions — memory for a world model driving dexterous manipulation, long-term memory for language agents, and injecting structured world knowledge into generative models so that it transfers from the visual to the action domain.

Selected projects

ScaleEdit: physically scale-consistent object replacement
Undergraduate thesis, sole investigator

Image-editing models place a replacement object at a plausible-looking but physically wrong size, and no existing benchmark measures it. I quantified the distortion, built an object-replacement benchmark grounded in real-world size priors with a consistency protocol combining 3D geometry and VLM judging, then proposed scale-aware supervised fine-tuning — lifting FLUX.2-Klein-9B from 45.8 to 60.4 overall. Problem, benchmark and method are all my own.

Mahjong VLA: a bimanual robot playing a live match
ModelBest Inc. · project owner, two-person team

Full single-view closed loop — tile perception → state tracking → policy → VLA control — driving a bimanual ALOHA robot through a live two-player game: a long-horizon, imperfect-information task on real hardware. Perception reached 91.2% exact match on full-hand tile sequences; GRPO raised the first-place rate from 18.3% to 31.7% over 448 half-games.
